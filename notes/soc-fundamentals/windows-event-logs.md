# Windows Event Logs

## Overview

Windows Event Logs are records generated by Windows and applications that help administrators and security analysts monitor system activity, troubleshoot issues, and investigate security incidents.

You can view these logs through:

```text
Event Viewer
└── Windows Logs
```

---

# 1. Application Logs

## Definition

Application logs contain events generated by software applications running on Windows.

If an application starts, stops, crashes, encounters an error, or records information, it writes events to the Application log.

## Common Events

- Application startup
- Application shutdown
- Application crashes
- Application errors
- Warning messages
- Information messages

## Location

```text
Event Viewer
└── Windows Logs
    └── Application
```

## SOC Use Cases

- Investigate application crashes
- Detect application errors
- Troubleshoot software issues
- Identify abnormal application behavior

---

# 2. Security Logs

## Definition

Security logs record security-related events generated by Windows auditing.

These are among the most important logs for SOC analysts.

## Common Events

- Successful Logons
- Failed Logons
- Account Creation
- Password Changes
- Process Creation
- Privilege Usage
- Account Lockouts
- Group Membership Changes

## Important Event IDs

| Event ID | Description |
|-----------|-------------|
| 4624 | Successful Logon |
| 4625 | Failed Logon |
| 4688 | Process Creation |
| 4720 | User Account Created |
| 4740 | Account Locked Out |

## Location

```text
Event Viewer
└── Windows Logs
    └── Security
```

## SOC Use Cases

- Brute-force detection
- User activity monitoring
- Privilege escalation detection
- Account compromise investigations
- Insider threat investigations

---

# 3. System Logs

## Definition

System logs contain events generated by Windows operating system components.

These logs focus on system functionality and hardware/software operations.

## Common Events

- Device Driver Activity
- Service Start/Stop
- Hardware Events
- System Startup
- System Shutdown
- System Errors

## Location

```text
Event Viewer
└── Windows Logs
    └── System
```

## SOC Use Cases

- Investigate system crashes
- Detect service failures
- Monitor device driver issues
- Analyze reboot activity

---

# 4. Setup Logs

## Definition

Setup logs record events related to Windows installation, upgrades, and update processes.

## Common Events

- Windows Installation
- Windows Upgrades
- Windows Feature Installation
- Windows Updates

## Location

```text
Event Viewer
└── Windows Logs
    └── Setup
```

## SOC Use Cases

- Verify update installation
- Investigate failed upgrades
- Confirm patch deployment
- Troubleshoot installation issues

---

# 5. Forwarded Events

## Definition

Forwarded Events contain logs received from other computers through Windows Event Forwarding (WEF).

Instead of checking logs on every machine, logs can be centralized and viewed from one system.

## Location

```text
Event Viewer
└── Windows Logs
    └── Forwarded Events
```

## SOC Use Cases

- Centralized monitoring
- Log aggregation
- SIEM integration
- Enterprise-wide visibility

---

# Windows Logs Summary

| Log Type | Purpose |
|-----------|----------|
| Application | Events generated by applications |
| Security | Security and audit events |
| System | Windows OS and hardware events |
| Setup | Installation and update events |
| Forwarded Events | Logs received from other computers |

# Which Logs Matter Most for SOC?

### Highest Priority

1. Security Logs
2. Sysmon Logs
3. PowerShell Logs

### Medium Priority

4. System Logs
5. Application Logs

### Lower Priority

6. Setup Logs
7. Forwarded Events (unless used in centralized logging)

# Interview Question

## Which Windows Log Is Most Important for a SOC Analyst?

Answer:

The Security Log is the most important because it records authentication activity, account changes, privilege usage, process creation, and other security-relevant events that help detect attacks and investigate incidents.

Common Event IDs:

- 4624 → Successful Logon
- 4625 → Failed Logon
- 4688 → Process Creation
- 4720 → User Account Created
- 4740 → Account Locked Out
