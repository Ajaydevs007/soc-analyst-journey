# Events, Logs, Logging, and Incidents

## Event

### Definition

An event is any observable occurrence in a system, network, application, or security device.

An event may or may not be security-related.

### Examples

- User login
- File creation
- USB insertion
- Service started
- Application crash

### Key Point

Not every event is a security threat.

---

## Log

### Definition

A log is a record that stores details about an event.

### Example

```text
2026-06-08 10:15:20
User: Ajay
Action: Login Success
Source IP: 192.168.1.10
```

### Key Point

Events happen.

Logs record those events.

---

## Logging

### Definition

Logging is the process of collecting, storing, and managing logs.

### Purpose

- Monitoring systems
- Troubleshooting issues
- Security investigations
- Compliance requirements

### Example

Windows Event Viewer stores system and security logs generated by Windows.

---

## Incident

### Definition

A security incident is a confirmed security event that has caused or may cause harm to a system, network, or organization.

### Examples

- Malware infection
- Brute-force attack
- Data breach
- Unauthorized access

### Key Point

Every incident is an event.

Not every event is an incident.

---

## Event vs Log vs Incident

| Term | Meaning |
|--------|--------|
| Event | Something happened |
| Log | Record of what happened |
| Incident | Harmful event requiring action |

### Example Flow

```text
User login attempt
        ↓
Event

Windows records it
        ↓
Log

100 failed logins detected
        ↓
Incident
```
