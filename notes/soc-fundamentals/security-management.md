# Security Management

Security Management is the process of planning, implementing, monitoring, and improving security controls to protect systems, networks, and data.

---

## 1. Security Infrastructure

Security Infrastructure refers to the foundation of security within an organization. It includes the technical components used to protect systems and networks.

### Components

- Firewalls
- IDS/IPS (Intrusion Detection and Prevention Systems)
- VPNs
- Endpoint Protection
- Network Segmentation

### Purpose

To build a secure environment where systems and data can operate safely.

### Example

In a company, servers are placed behind firewalls and access is controlled using authentication systems.

---

## 2. Security Protection

Security Protection focuses on preventing attacks and reducing security risks before they can cause damage.

### Includes

- Patch Management
- Vulnerability Scanning
- Secure Coding Practices
- Security Awareness Training (Phishing Awareness)
- Access Control (Least Privilege)

### Purpose

To stop cyber attacks before they happen and minimize potential risks.

### Example

Regularly patching operating systems and applications to prevent attackers from exploiting known vulnerabilities.

---

## 3. GRC (Governance, Risk, and Compliance)

GRC is the management and decision-making layer of cybersecurity.

### Governance

Defines how security is managed within the organization.

Includes:

- Security Policies
- Rules and Standards
- Leadership Decisions
- Security Strategy

### Risk Management

Identifying, assessing, and managing threats and vulnerabilities that could impact the organization.

### Compliance

Ensuring the organization follows legal requirements, industry regulations, and security standards.

Examples:

- ISO 27001
- NIST
- PCI DSS
- GDPR

### Purpose

To ensure security is organized, measurable, and aligned with business goals.

### Example

A company creates a password policy and regularly audits whether employees follow it.

---

## 4. SOC (Security Operations Center)

A Security Operations Center (SOC) is the real-time defense team responsible for monitoring, detecting, investigating, and responding to security incidents.

### Responsibilities

- Monitoring tools and logs (SIEM)
- Detecting threats
- Investigating incidents
- Responding to attacks

### Common Tools

- Splunk
- QRadar
- Microsoft Sentinel
- Sysmon
- EDR/XDR Solutions

### Purpose

To detect and respond to cyber attacks as quickly as possible.

### Example

If an attacker performs a brute-force login attempt, the SOC detects the activity, investigates it, and blocks the malicious IP address.

---

# Relationship Between the Four Areas

```text
Security Management
│
├── Security Infrastructure
│   └── Provides the security foundation
│
├── Security Protection
│   └── Prevents attacks and reduces risks
│
├── GRC
│   └── Defines policies, manages risks, ensures compliance
│
└── SOC
    └── Monitors, detects, investigates, and responds to threats
```

# Key Takeaway

- **Security Infrastructure** → Security tools and technologies.
- **Security Protection** → Measures that prevent attacks.
- **GRC** → Governance, risk management, and compliance activities.
- **SOC** → Real-time monitoring and incident response team.

Together, these four areas form the foundation of an organization's cybersecurity program.
