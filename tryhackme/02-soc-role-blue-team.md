## Key Concepts

### SOC Team Structure
- **L1 — Triage Analyst**
  - Monitors SIEM alerts 24/7
  - First responder to alerts
  - Identifies false positives and true positives
  - Escalates confirmed threats to L2

- **L2 — Incident Responder**
  - Investigates escalated alerts from L1
  - Performs deeper log analysis
  - Contains and remediates incidents
  - Creates incident reports

- **L3 — Threat Hunter**
  - Proactively hunts for threats not caught by alerts
  - Creates and tunes detection rules
  - Performs forensic analysis
  - Mentors L1 and L2 analysts

### Other SOC Roles
- **SOC Manager** — oversees entire SOC operation
- **Threat Intelligence Analyst** — tracks threat actors and TTPs
- **Security Engineer** — builds and maintains security tools

### Blue Team vs Red Team
- **Blue Team** — defenders, detect and respond to attacks
- **Red Team** — attackers, simulate real world attacks
- **Purple Team** — combines both, improves detection through simulation

## Career Ladder
L1 Analyst → L2 Analyst → L3 / Threat Hunter  
→ SOC Lead → SOC Manager  
OR  
L1/L2 → GRC Analyst → GRC Consultant → GRC Manager

## One Thing to Remember
L1 is not a dead end job. Every senior SOC analyst,  
threat hunter, and GRC consultant started at L1.  
The speed at which you grow depends entirely on  
how deeply you learn at each level — not just how  
fast you move to the next title.
