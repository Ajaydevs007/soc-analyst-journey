# INV-027 — Distinct PDFs Encrypted on Remote File Server

## Question

How many distinct PDFs did the ransomware encrypt on the remote file server?

## Answer

257

## Workstation

we8105desk

## Workstation IP

192.168.250.100

## File Server

we9041srv.waynecorpinc.local

## File Server IP

192.168.250.20

## Investigation

The investigation focused on Windows Security Event ID 5145 events
generated by access to files on the remote network share.

The Relative_Target_Name field contains the individual filenames accessed
through the network share.

PDF files were isolated and their distinct filenames counted.

## Initial PDF Count

258 distinct PDF filenames were observed in the relevant access events.

However, not every accessed PDF was encrypted.

The file access permissions were examined to identify files for which the
ransomware had write access.

## Encrypted PDF Count

257

## SPL

index=botsv1
sourcetype="WinEventLog:*"
"*.pdf"
dest="we9041srv.waynecorpinc.local"
Source_Address="192.168.250.100"
| stats dc(Relative_Target_Name) as encrypted_pdfs

## Conclusion

The Cerber ransomware encrypted:

257 distinct PDF files

on the remote file server.

## Evidence Type

Direct BOTS v1 Windows Security / file-share telemetry.
