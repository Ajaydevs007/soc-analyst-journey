# INV-030 — Cerber Cryptor File Download

## Question

The malware downloads a file that contains the Cerber ransomware cryptor code. What is the name of that file?

## Answer

`mhtr.jpg`

## Host

- Host: `we8105desk`
- IP: `192.168.250.100`

## Investigation Path

1. Identify suspicious activity associated with the compromised workstation.
2. Investigate HTTP traffic generated by `192.168.250.100`.
3. Identify the suspicious domain:
   - `solidaritedeproximite.org`
4. Examine HTTP GET requests from the host.
5. Identify the downloaded file:
   - `mhtr.jpg`
6. Correlate the downloaded file with historical BOTS v1 analysis identifying it as the Cerber cryptor payload.

## Relevant URLs

- `http://solidaritedeproximite.org/mhtr.jpg`
- `http://92.222.104.182/mhtr.jpg`

## Evidence

HTTP activity associated with the compromised workstation shows:

`2016/08/24 16:48:13.285`
`http://solidaritedeproximite.org/mhtr.jpg`

A subsequent request was observed for:

`2016/08/24 16:48:14.620`
`http://92.222.104.182/mhtr.jpg`

## Conclusion

The file downloaded by the malware that contains the Cerber ransomware cryptor code is:

`mhtr.jpg`

The `.jpg` extension is significant because the malicious code is disguised as an image file.
