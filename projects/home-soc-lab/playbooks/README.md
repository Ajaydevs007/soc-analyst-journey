# SOC Playbooks

These playbooks provide standardized investigation procedures for recurring security alerts observed during the Home SOC Lab project.

## Available Playbooks

| Playbook | Purpose |
|----------|---------|
| Network Reconnaissance | Investigate network scanning activity |
| Brute Force | Investigate repeated authentication failures |
| Successful Authentication | Validate potentially suspicious logins |
| Command Execution | Investigate process creation events |
| Persistence | Investigate unauthorized account creation and persistence |
