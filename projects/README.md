# SOC Projects

This directory contains practical SOC lab projects and structured investigations. Each project has its own README with scope, setup, methodology, findings, and supporting evidence.

## Featured Projects

### [Detection Lab — Active Directory + Microsoft Sentinel](Detection-Lab/README.md)

A controlled Kerberos password-spray simulation in an Active Directory lab. Documents Windows Security telemetry, Azure Monitor Agent and Log Analytics ingestion, KQL detection logic, a scheduled Microsoft Sentinel analytics rule, and generated incident evidence.

### [Home SOC Lab — Splunk + Sysmon](home-soc-lab/README.md)

A Windows and Kali lab using Sysmon, Windows Event Logs, Splunk Enterprise, and the Splunk Universal Forwarder. Includes attack simulations, log analysis, MITRE ATT&CK mappings, detection work, incident reports, and playbooks.

### [Splunk Bots v1 Investigation](splunk-bots-v1-investigation/README.md)

A dataset investigation organized into SPL queries, investigation notes, reports, playbooks, and a timeline.

## Scope and Evidence

The projects are learning exercises performed in controlled environments. Refer to each project README for its own status and evidence. Planned extensions are not represented as completed work.
