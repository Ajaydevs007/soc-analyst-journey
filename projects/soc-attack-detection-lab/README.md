# SOC Attack Detection Lab

## Overview
This project simulates a cyber attack in a home SOC lab environment using Kali Linux, Windows, Sysmon, and Splunk.

The objective is to detect and investigate attacker activity using Windows Event Logs and Sysmon telemetry inside Splunk.

---

## Tools Used
- Splunk Enterprise
- Splunk Universal Forwarder
- Sysmon
- Kali Linux
- Nmap
- Hydra
- Windows 10/11 VM

---

## Attack Phases
1. Reconnaissance
2. Brute Force
3. Successful Login
4. Post Exploitation
5. Detection and Investigation
6. Incident Reporting
