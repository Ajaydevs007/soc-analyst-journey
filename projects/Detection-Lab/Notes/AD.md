Active Directory (AD)

AD = Active Directory

Active Directory is a directory environment that stores and organizes information about an organization's:

Users
Computers
Groups
Policies
Other objects

Think of AD like a database/directory for an organization.

AD
├── Users
│   ├── Ajay
│   └── Admin
├── Computers
│   ├── PC01
│   └── PC02
└── Groups

AD = The directory/environment where organizational information is stored and organized.
